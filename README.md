# CyberSim Knowledge Base

Investigación sobre **evaluación de competencias de seguridad ya adquiridas por estudiantes de ingeniería de software**, mediante tareas y evidencias en escenarios 3D.

El cierre original del 13-11-2026 contiene 120 publicaciones recientes distintas cribadas y 15 textos completos. La ampliación del 15–16-11-2026 comprueba abstract y cierre de **50 publicaciones distintas**, 47 ya registradas y tres incorporaciones; completa el fundamento de la selección y añade dos lecturas integrales. El inventario actual tiene **137 fichas canónicas, 17 textos completos con alcance declarado y seis PDF originales conservados**. Los recuentos de fases solapadas no se suman como publicaciones independientes.
