# Cyber ranges - Lecciones entre niveles educativos

**P033. Lessons Learned from Using Cyber Range to Teach Cybersecurity at Different Levels of Education.**

[Fuente original o ficha de autor](https://doi.org/10.1007/s10758-025-09840-y) · Consulta: 13-11-2026.

## Aporte

Recoge percepciones y experiencias educativas; menciona tensión entre competencia, estrés y uso de pistas.

## Límite y valoración

Los datos de percepción no validan una regla de puntuación ni una penalización uniforme por ayuda.

## Decisión para CyberSim

Separar apoyo instrumental y ayuda de contenido; observar abandono y accesibilidad en piloto. Esta aplicación es una inferencia de diseño local; no un resultado experimental en CyberSim.
