# Anti-Phishing AG - Juego web tridimensional

**P017. Design and Development of Anti-Phishing AG: A Web-Based 3D Serious Game to Improve Phishing Awareness Among Students in Saudi Arabia.**

[Fuente original o ficha de autor](https://etasr.com/index.php/ETASR/article/view/18035) · Consulta: 13-11-2026.

## Aporte

Describe un juego 3D web y una evaluación antes/después con 702 escolares.

## Límite y valoración

Otra población, amenaza y constructo; el diseño de un solo grupo no aísla el efecto causal de 3D.

## Decisión para CyberSim

Útil para factibilidad web, no como validación de las rúbricas de CyberSim. Esta aplicación es una inferencia de diseño local; no un resultado experimental en CyberSim.
