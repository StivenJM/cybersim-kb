# SecretBench - Verdad de referencia de secretos

**P039. SecretBench: A Dataset of Software Secrets.**

[Fuente original o ficha de autor](https://bradreaves.net/publication/bnrw23b/) · Consulta: 13-11-2026.

## Aporte

Dataset etiquetado para evaluar detección de secretos en repositorios.

## Límite y valoración

No importar secretos reales a un ejercicio educativo ni confundir evaluación de detectores con evaluación del alumno.

## Decisión para CyberSim

Construir fixtures sintéticos con verdad conocida y distractores benignos. Esta aplicación es una inferencia de diseño local; no un resultado experimental en CyberSim.
