# Seguridad - Aprendizaje contextual para desarrolladores

**P077. Context-Based Support to Enhance Developers’ Learning of Software Security.**

[Fuente original o ficha de autor](https://www.mdpi.com/2227-7102/13/7/631) · Consulta: 13-11-2026.

## Aporte

Diseña un sistema ontológico de aprendizaje contextual y evalúa perspectivas de estudiantes y desarrolladores.

## Límite y valoración

Satisfacción y utilidad percibida no acreditan transferencia ni dominio profesional.

## Decisión para CyberSim

Solicitar al estudiante una explicación contextual que relacione sus decisiones con el código del escenario; no incorporar la enseñanza contextual como parte de la evaluación. Esta aplicación es una inferencia de diseño local; no un resultado experimental en CyberSim.
