# LLM - Extracción de datos memorizados

**P124. Scalable Extraction of Training Data from Aligned, Production Language Models.**

[Fuente original o ficha de autor](https://proceedings.iclr.cc/paper_files/paper/2025/file/cce0e917b050208170151f77b497fc71-Paper-Conference.pdf) · Consulta: 13-11-2026.

## Aporte

Muestra extracción mediante divergencia y ajuste en versiones históricas de modelos alineados.

## Límite y valoración

Resultados de versiones de 2023–2024; reconocer PII no prueba su origen privado y filtros son imperfectos.

## Decisión para CyberSim

Distinguir fuga por contexto, autorización y memorización; mantener datos sintéticos en pruebas. Esta aplicación es una inferencia de diseño local; no un resultado experimental en CyberSim.
