# LLM - Seguridad de respuestas de programación

**P047. Do LLMs consider security? an empirical study on responses to programming questions.**

[Fuente original o ficha de autor](https://doi.org/10.1007/s10664-025-10658-6) · Consulta: 13-11-2026.

## Aporte

Estudia respuestas de Claude 3, GPT-4 y Llama 3 a preguntas con código vulnerable, observando advertencias y explicación de causas, explotación y correcciones.

## Límite y valoración

Evalúa salidas de modelos, no competencia humana; sus resultados dependen del dataset y las versiones estudiadas.

## Decisión para CyberSim

Candidato para la competencia de revisión crítica de código sugerido por IA. Esta aplicación es una inferencia de diseño local; no un resultado experimental en CyberSim.

## Alcance de lectura

**resumen-conclusiones**. Cuenta en la cuota reciente.

Abstract y conclusión 354–362; fallos de advertencia en tres LLM, dependencia de versión y dataset.
