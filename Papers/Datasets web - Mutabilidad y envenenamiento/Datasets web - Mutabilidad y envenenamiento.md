# Datasets web - Mutabilidad y envenenamiento

**P121. Poisoning Web-Scale Training Datasets is Practical.**

[Fuente original o ficha de autor](https://arxiv.org/pdf/2302.10149) · Consulta: 13-11-2026.

## Aporte

Demuestra riesgos por vistas distintas del contenido web y ventanas de captura de datos.

## Límite y valoración

Capacidad práctica para contaminar corpus no es medida de competencia ni prueba de ataque ocurrido en CyberSim.

## Decisión para CyberSim

Verificar hashes, procedencia y versionado; una URL conocida no garantiza contenido inmutable. Esta aplicación es una inferencia de diseño local; no un resultado experimental en CyberSim.
