# EDURange - Intervención docente desde trazas

**P125. From Logs to Learning: Applying Machine Learning to Instructor Intervention in Cybersecurity Exercises.**

[Fuente original o ficha de autor](https://edurange.org/docs/EDURange_ASEE2024.pdf) · Consulta: 13-11-2026.

## Aporte

Desarrolla clasificación de progreso y chat para sugerir ayudas que el docente puede rechazar.

## Límite y valoración

Prueba de concepto; eficacia y localización precisa dentro de escenarios siguen en desarrollo.

## Decisión para CyberSim

Usar trazas y revisión humana para interpretar la actuación; registrar cualquier intervención docente que afecte la autonomía observada. Esta aplicación es una inferencia de diseño local; no un resultado experimental en CyberSim.
