# BIPIA - Límites entre instrucciones y datos

**P122. Benchmarking and Defending Against Indirect Prompt Injection Attacks on Large Language Models.**

[Fuente original o ficha de autor](https://arxiv.org/pdf/2312.14197) · Consulta: 13-11-2026.

## Aporte

Benchmark de inyección indirecta y defensas de límites de contenido, recordatorios y ajuste.

## Límite y valoración

Resistencia dentro de benchmark/modelos; resultados cercanos a cero no prueban seguridad universal.

## Decisión para CyberSim

Probar entradas adversariales nuevas y utilidad legítima; separar datos externos de autoridad. Esta aplicación es una inferencia de diseño local; no un resultado experimental en CyberSim.
